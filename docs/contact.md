# Collaborate

!!! warning "Work in progress"
    RLQuantOpt v2 is open-source, **active research** by Leander Grech. The code, the numbers on
    these pages and the conclusions drawn from them may change as the work goes on. Please cite the
    published paper ([Grech et al., *Quantum Sci. Technol.* 11, 015030 (2026)](https://doi.org/10.1088/2058-9565/ae2c16))
    for anything settled, and treat the rest as a lab notebook.

Collaboration is welcome, especially on:

- **Hardware validation** of RL or GRAPE pulses on a superconducting device;
- **device models** beyond the paper's Hamiltonian: realistic tunable couplers, the double-transmon
  coupler, fluxonium (see the
  [roadmap](v2_jax_plan.md));
- **RL methods**: model-based and meta-RL, robustness to drift;
- **optimal-control baselines** and fair comparisons.

## Get in touch

[Open a collaboration request :material-account-plus:](https://github.com/leandergrech/rlquantopt/issues/new?template=collaboration.yml){ .md-button .md-button--primary }

The button opens a short form on GitHub (you need a free GitHub account). It creates a public
issue, so keep confidential details out of it and ask for a private follow-up instead.

For questions about the code, [open a regular issue](https://github.com/leandergrech/rlquantopt/issues/new).
